# 🎬 AndFilm — Premium Personal Media Library

Welcome to **AndFilm**, a modern, fast, and highly interactive online cinema and live streaming interface. This project was built completely from scratch as a personal challenge to master modern web technologies, pixel-perfect layout design, and dynamic user interfaces.


---

## ✨ Features & Core Logic

- **Custom Theme Engine:** A fully dynamic Dark/Light theme controller engineered in pure JavaScript using CSS Custom Properties (`:root`) and dynamic properties change. 🌗
- **Futuristic UI Elements:** Interactive theme buttons with custom mechanical translation animations (`translateY`).
- **Micro-interactions:** Smooth animations (`scroll-behavior: smooth`) and dedicated custom navigation anchors ("Go TOP") to maximize accessibility.

---

## 🗂️ Technologies Used

- **HTML5:** Semantic architecture, fully structured data trees.
- **CSS3:** Advanced typography mapping, custom animations, transitions, and flexible layouts.
- **JavaScript (ES6+):** Event listener bindings, inline structural modifiers, dynamic style generation.
- **Google Fonts:** Integration of unique typography styling.
